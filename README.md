언리얼 포트폴리오반 예제

1. 수업 목적

언리얼 포트폴리오반에서 학습한 내용을 실제 포트폴리오 형태의 예제로 연결하기 위한 문서입니다.

기본적인 언리얼 엔진 사용법을 익힌 뒤 FPS 장르를 기반으로 게임의 핵심 시스템을 직접 구현하고, 이를 포트폴리오에 정리할 수 있도록 구성합니다.

2. 예제 프로젝트

언리얼 FPS 장르 템플릿 수업중 예제

언리얼 엔진의 FPS 장르 템플릿을 기반으로 프로젝트를 구성합니다.

수업에서는 템플릿에 이미 구현되어 있는 기능을 단순히 사용하는 것에서 끝내지 않고, 각 기능이 어떤 구조로 동작하는지 확인하고 필요한 기능을 직접 확장하는 방식으로 진행합니다.

예제의 주요 방향은 다음과 같습니다.
- FPS 캐릭터 구조 이해
- 플레이어 이동과 입력 처리
- 카메라 및 시점 제어
- 무기 시스템
- 발사 처리
- 탄약 및 재장전
- 적 캐릭터

피격 및 데미지 처리

체력 시스템

UI 구성

게임 상태 관리

사운드 및 이펙트

레벨 구성
